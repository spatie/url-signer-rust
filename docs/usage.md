A signer-object can sign URLs and validate signed URLs. A secret key is used to generate signatures.

```rust
# fn main() -> Result<(), spatie_url_signer::Error> {
use spatie_url_signer::Sha256UrlSigner;

let url_signer = Sha256UrlSigner::new("mysecretkey")?;
# let signed_url = url_signer.sign("https://myapp.com", 30)?;
# assert!(url_signer.validate(&signed_url));
# Ok(())
# }
```

## Generating URLs

Signed URLs can be generated by providing a regular URL and an expiration date to the `sign` method. Use `Expiration::Timestamp` for an absolute Unix timestamp in seconds.

```rust
# use spatie_url_signer::{Sha256UrlSigner, Expiration};
# fn main() -> Result<(), spatie_url_signer::Error> {
# let url_signer = Sha256UrlSigner::new("mysecretkey")?.with_clock(|| 1_700_000_000);
# let now = 1_700_000_000_i64;
let expiration_date = Expiration::Timestamp(now + 10 * 24 * 60 * 60);

let signed_url = url_signer.sign("https://myapp.com", expiration_date)?;

// The generated URL will be valid for 10 days.
# assert!(url_signer.validate(&signed_url));
# assert!(signed_url.contains("expires=1700864000"));
# Ok(())
# }
```

If an integer is provided as expiration date, the URL will be valid for that amount of seconds.

```rust
# use spatie_url_signer::Sha256UrlSigner;
# fn main() -> Result<(), spatie_url_signer::Error> {
# let url_signer = Sha256UrlSigner::new("mysecretkey")?;
let signed_url = url_signer.sign("https://myapp.com", 30)?;

// The generated URL will be valid for 30 seconds.
# assert!(url_signer.validate(&signed_url));
# Ok(())
# }
```

Past expirations and timestamp overflow return `Error::InvalidExpiration`. Zero seconds is allowed. An empty default key returns `Error::InvalidSignatureKey`.

## Validating URLs

To validate a signed URL, simply call the `validate()` method. This will return a boolean.

```rust
# use spatie_url_signer::Sha256UrlSigner;
# fn main() -> Result<(), spatie_url_signer::Error> {
# let url_signer = Sha256UrlSigner::new("mysecretkey")?;
# let signed_url = url_signer.sign("https://myapp.com", 30)?;
assert!(url_signer.validate(&signed_url));

let forged_url = signed_url.replace("myapp.com", "somewhereelse.com");
assert!(!url_signer.validate(&forged_url));
# Ok(())
# }
```

The expiration check is inclusive: a URL expiring at Unix second 100 is valid at second 100 and invalid at second 101. Malformed or missing expiration/signature values return `false`, including array-valued signing parameters. Signature comparison uses constant-time comparison for equal-length values.

Use a cryptographically random secret and keep it out of URLs, logs and source control. Signing does not encrypt the URL or prevent replay before expiration. Your application must enforce authorization and use HTTPS.

## Custom keys and parameter names

You can override the default key for an individual URL. Both sides must use the same key and parameter names.

```rust
# use spatie_url_signer::Sha256UrlSigner;
# fn main() -> Result<(), spatie_url_signer::Error> {
let url_signer = Sha256UrlSigner::new("mysecretkey")?
    .with_parameter_names("until", "hash");

let signed_url = url_signer.sign_with_key("https://myapp.com", 30, "custom-key")?;
assert!(url_signer.validate_with_key(&signed_url, "custom-key"));
assert!(!url_signer.validate_with_key(&signed_url, "wrong-custom-key"));
# Ok(())
# }
```

Choose distinct plain names without spaces, dots or brackets. Other names may be transformed by the query parser and produce unverifiable links. Always use a nonempty, cryptographically random key, including for per-call overrides.

## Writing custom signers

This package provides a signer that uses SHA256 to generate signatures. You can create your own signer by implementing `SignatureAlgorithm`. `UrlSigner::with_algorithm` supplies query handling, expiration and signature validation.

```rust
# use spatie_url_signer::{Sha256, SignatureAlgorithm, UrlSigner};
# fn main() -> Result<(), spatie_url_signer::Error> {
#[derive(Debug)]
struct CustomSigner;

impl SignatureAlgorithm for CustomSigner {
    fn create_signature(&self, url: &str, expiration: &str, key: &str) -> String {
        Sha256.create_signature(url, expiration, key)
    }
}

let url_signer = UrlSigner::with_algorithm("mysecretkey", CustomSigner)?;
let signed_url = url_signer.sign("https://myapp.com", 30)?;
# assert!(url_signer.validate(&signed_url));
# Ok(())
# }
```

`Md5UrlSigner` can validate existing links using the legacy MD5 algorithm. It is not HMAC-MD5. Use `Sha256UrlSigner` for new links.

## URL normalization and shared links

SHA256 signatures use hex HMAC-SHA256 over `url::expiration`. The legacy MD5 signer hashes `url::expiration::key`. Use SHA256 for new links.

The URL text before the first `?` stays unchanged: no added slash, hostname lowercasing, default-port removal or path cleanup. Query order is retained, duplicate scalar keys keep the last value, nested PHP arrays are rebuilt, spaces become `+`, and query names containing dots or spaces become underscores. Existing signature and expiration parameters are removed before signing.

Avoid fragments in signed links used by browsers. The signer treats the input as text. For example, `https://myapp.com?x=value#section` becomes a query containing `x=value%23section`. With no `?`, `#section` stays in the base and the signing parameters follow it. A browser will not send its fragment to your server.

Use named top-level query keys. Integer keys are renumbered when the signing parameters are appended and can produce an unverifiable URL.

For links shared with [spatie/url-signer](https://github.com/spatie/url-signer), use 64-bit PHP 8.3+ with `arg_separator.input=&`, `arg_separator.output=&`, `max_input_vars=1000`, and `max_input_nesting_level=64`. PHP 8.2 assigns different appended array indices after negative keys; use explicit nonnegative indices for links shared with that runtime. Changing PHP's INI settings can change signatures. Rust strings must be UTF-8; percent-encoded arbitrary query bytes are preserved, but raw non-UTF-8 URL/key input is not representable.

## Testing the expiry boundary

Use `with_clock` to supply a clock returning Unix seconds. Production signers use the system clock.

```rust
# use spatie_url_signer::Sha256UrlSigner;
# fn main() -> Result<(), spatie_url_signer::Error> {
let url_signer = Sha256UrlSigner::new("mysecretkey")?.with_clock(|| 100);
let signed_url = url_signer.sign("https://myapp.com", 0)?;
assert!(url_signer.validate(&signed_url));
assert!(!url_signer.with_clock(|| 101).validate(&signed_url));
# Ok(())
# }
```
