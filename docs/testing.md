Run these checks from the package directory:

```sh
cargo fmt --all -- --check
cargo clippy --locked --all-targets --all-features -- -D warnings
cargo test --locked --all-targets --all-features
cargo test --locked --doc --all-features
cargo doc --locked --no-deps --all-features
cargo package --locked
```

Set `RUSTDOCFLAGS` to `-D warnings` when running the documentation commands. In POSIX shells, prefix each command with `RUSTDOCFLAGS='-D warnings'`. In PowerShell, first run `$env:RUSTDOCFLAGS = '-D warnings'`.

README.md and all Markdown pages in docs/ participate in rustdoc tests. Setup lines prefixed with `# ` compile and execute but are hidden in rendered rustdoc. Assertions check the examples' results.

Check the minimum supported Rust version:

```sh
rustup toolchain install 1.89.0 --profile minimal
cargo +1.89.0 test --locked --all-targets --all-features
cargo +1.89.0 test --locked --doc --all-features
```

Check security advisories:

```sh
cargo install cargo-audit --locked
cargo audit
```

CI runs stable checks on Linux, macOS and Windows, and the MSRV and audit checks on Linux. An audit requires access to the RustSec advisory database.

## PHP interoperability

The regular suite checks committed fixtures generated by the actual PHP package, without requiring PHP locally. The live differential suite requires PHP 8.3 or newer and the pinned reference source. It compares the exact signed URL and both implementations' validation results before, at, and after expiration. It also checks tampering, malformed signing parameters, duplicate query parameters, encoding, nested arrays, fragments, numeric keys and PHP's default input limits.

```sh
git clone https://github.com/spatie/url-signer.git php-url-signer
git -C php-url-signer checkout 3cddceff31fcbffc19ee21e5abf7cbf6c196292e
PHP_URL_SIGNER_SOURCE="$PWD/php-url-signer" cargo test --locked --test interop differential_against_php -- --ignored --nocapture
```

On PowerShell set `$env:PHP_URL_SIGNER_SOURCE = "$PWD/php-url-signer"` before running the Cargo command. The source checkout has no runtime dependencies, so Composer installation is not needed. The PHP test subclasses translate the frozen timestamps to the system clock and call the upstream expiry comparison itself, retrying if the second rolls over. Signing, normalization and validation run the upstream code. CI runs this test explicitly on PHP 8.3 and 8.4.

Fixture provenance is the same pinned commit. `tests/php/oracle.php` accepts a JSON array of cases on stdin and emits signed URLs and validation results. `tests/php/fixtures.json` contains independently PHP-generated inputs and expectations; the seeded live cases are generated by `tests/interop.rs`.
